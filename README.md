
SkinInsight – Skincare Product Rating Prediction

Project Overview
SkinInsight is a Machine Learning project that predicts the average customer rating of skincare products using Linear Regression.

Objective
To study the relationship between skincare product features and customer ratings and build a model to predict product ratings.

Dataset
Sephora Products and Skincare Reviews dataset.

Dataset Source:
https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews

Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Machine Learning Algorithm
Linear Regression

Workflow
1. Dataset loading
2. Data exploration
3. Data cleaning
4. Data preprocessing
5. Feature selection
6. Train-test splitting
7. Model training
8. Rating prediction
9. Model evaluation

Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

Conclusion
The project demonstrates how Linear Regression can be applied to skincare product rating prediction using real-world product data.
